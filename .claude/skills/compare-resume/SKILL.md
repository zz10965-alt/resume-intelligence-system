# Compare Resume

对比两个简历版本，解释「改了什么、为什么改」。

## 步骤

1. 定位两个版本（Base vs Target，或 v1 vs v2）。
2. 对比维度：
   - 用了哪些经历/项目（是否一致，见 VARIANT_CONSISTENCY.md）
   - bullet 选择/顺序/措辞差异
   - skills 顺序差异
   - 关键词增删
   - 每个变化由哪个 JD 要求驱动
3. 生成差异说明：Changed / Why / Driven-by 三栏。

## 输出
结构化差异表 + 一句话总结（「主要为了 X 岗位的 Y 要求而调整了 Z」）。
