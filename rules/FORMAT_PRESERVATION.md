# FORMAT_PRESERVATION.md —— 原始简历格式保留（硬约束）

> 用户提供的中英文简历 DOCX 是「**格式母版**」。生成变体时保留其整体版式，**只改内容**；字体/间距可按内容微调以维持一页。

## 永远不可改动

- **照片**（中文简历含照片）—— 绝不删除、替换、移动
- **个人信息**（姓名、邮箱、电话、地址、链接等）—— 内容与排版都不动
- **各 Section 顺序**（Education → Professional Experience → Projects → Skills 等）—— 不动

## 可调整（服务于「保持一页」）

- **字体大小**
- **行距**（line spacing）
- **段落间距**（paragraph spacing）

> 调整原则：保证**恰好一页**，不溢出、不留大片空白；只能微调，不改变整体版式观感。

## 只改内容

- 每条 bullet 的**措辞/表述**（Action / Method / Result 写法）
- 关键词的自然融入
- 同一 Section 内部 bullet 的**选择与排序**（属于「内容」，允许）

## Bullet 排满要求

- 实习 / 项目 bullet 若占两行，须**基本排满这两行**，第二行不得只剩几个字空着。
- 做法：用「控制 bullet 措辞长度」+「必要时微调字体/行距」配合，让每条 bullet 落在**整一行 / 整两行**，避免 1.2 行、2.3 行这类悬挂短行。

## 实现方式

- 以用户**原始 DOCX 为格式母版**，用 python-docx **原地替换文本内容**，保留照片 / 个人信息 / section 顺序。
- **不通过 Markdown 重新生成 DOCX**（那会丢失照片与自定义版式）。
- Markdown 仍作为「内容源」用于版本控制 / diff / 内容编辑；导出时把内容**注入 DOCX 母版**，而非重建。

## 红线

- 绝不删除 / 替换照片；绝不动个人信息格式；绝不动 Section 顺序
- 导出后必须核对：照片在、个人信息原样、section 顺序没变、恰好一页、无悬挂短行
