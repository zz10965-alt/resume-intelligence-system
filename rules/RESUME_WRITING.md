# RESUME_WRITING.md —— 简历写法规范

## 1. Bullet 结构

一般遵循：**Action + Method + Context + Result / Finding / Impact**

但不要机械地让每条 bullet 都套同一结构。优先：具体性、清晰度、业务相关性、技术可信度、量化、ATS 相关性。

## 2. 语言要自然，不要有「AI 味」（硬要求）

写出来的 bullet 要读起来像**一个真实的人在描述自己的工作**，不是模板批量生成的。

**避免：**
- 套路化句式：每条都「负责…」「通过…实现了…」「基于…为…赋能」
- 空泛形容词：significant、successfully、effectively、高效、有力、显著（后面没数字时）
- 空话 buzzword：赋能、闭环、抓手、对齐、颗粒度、沉淀方法论（无实质内容时）
- 句式单调：每条 bullet 结构一模一样
- 中文简历逐句直译英文

**要：**
- 具体、有信息量的动词，句式有变化
- 一句话说清「做了什么 + 结果是什么」
- 短、有力、像人话

## 3. 参考用户原简历的措辞

- 用户原简历（中英）是**语言风格参照**，措辞自然、可信。
- **原本就写得好、且真实的 bullet，直接保留 / 复用**，不要为了改写而改写。
- 只在以下情况才改：角色侧重不同、需要补量化、需要自然融入 ATS 关键词、需要去掉 AI 味 / 空话。

## 4. 量化（重点：数据量）

- **能放的数字尽量放，尤其是数据量 / 数据规模**：如「100 万行订单」「5000 份问卷」「120GB 日志」「3 个市场 × 200 样本」。
- 数字来自证据，**可以四舍五入 / 按量级**（146231 →「15 万」），但**不编不存在的数字**。
- 证据有精确数就用精确数（或四舍五入后的数）；只有模糊描述时，用保守模糊表述（「上百万」「数千」）或干脆不写，**不要凭空捏一个看似精确的数字**。

## 5. 动词与措辞

- 优先具体、有信息量的动作词。
- 同一份简历内避免动词重复。

## 6. 角色化改写（配合 VARIANT_CONSISTENCY.md）

同一段经历、同一个项目，按角色改 framing：

- DA：突出数据处理、指标、监控、根因、可视化。
- BA：突出业务驱动、洞察、建议、策略、决策支持。
- DS：仅在真实存在时突出统计 / 实验 / 建模。
- AI Analytics：仅在真实做过时突出分析自动化、AI 辅助。

改写只动 bullet 选择 / 顺序 / 措辞 / 强调，不动事实。

## 7. 语言（中美）

- US：更简洁、ATS 重、action/result 导向，遵循美式简历惯例。
- China：可强调业务背景、分析方法、发现、业务含义、业务价值；中文简历要自然，不要逐句机械翻译英文 bullet。
