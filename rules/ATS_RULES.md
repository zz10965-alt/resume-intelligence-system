# ATS_RULES.md —— ATS 关键词与解析安全

## 1. 定位

ATS 是「可读性」之一，不是「欺骗」目标。优化 ATS 关键词的**前提是真实**。

> 目标不是 trick ATS，而是为每个相关角色呈现**最强、最真实**的经历版本。

## 2. Section 命名

使用标准、可被 ATS 稳定解析的 section 名：

`EDUCATION` / `PROFESSIONAL EXPERIENCE` / `PROJECT EXPERIENCE` / `TECHNICAL SKILLS`

避免自定义花哨标题。

## 3. 解析安全

- 不用文本框、图片、图标堆砌（会被 ATS 破坏解析）。
- 不用 skill bar、装饰图表、复杂多栏布局。
- 避免照片、多余颜色、复杂排版。

## 4. 关键词使用

- JD 关键词应在**真实证据支持**的前提下自然融入。
- 「JD 关键词未被使用」要区分两类：
  - 因**不支持**而未用 → 记入 Match Report 的 `JD Keywords NOT Used Because Unsupported`。
  - 因**疏忽**未用 → 补齐。

## 5. 与真实性冲突时

**真实性优先。** 不允许为命中关键词而虚构。
