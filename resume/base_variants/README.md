# Base Resume Variants

> 基于 Master Resume 建立的稳定 Base Resume。不同版本**不是不同的人**，核心事实一致（85–90% 经历/身份一致）。

## 变体清单

| 变体 | 市场 | 方向 |
|---|---|---|
| `CN_DA.md` | China | Data Analyst |
| `CN_BA.md` | China | Business Analyst |
| `CN_DS.md` | China | Data Scientist |
| `CN_AI_Analytics.md` | China | AI Analytics |
| `US_DA.md` | US | Data Analyst |
| `US_BA.md` | US | Business Analyst |
| `US_DS.md` | US | Data Scientist |

## 规则
- 主要变化：bullet 选择/顺序、措辞、侧重点、Skills 顺序、Project 顺序、支持关键词。
- 同实习 + 约 2 个同项目（硬约束，见 `rules/VARIANT_CONSISTENCY.md`）。
- 仅真实支持的统计/实验/建模/AI 才在 DS/AI 版强调。
